How it works

Methodology

Question tiers

  • Tier 1 — Factual (10 q): Short lookups. Shannon entropy, IRAP, UCB1, Schnorr. Scored by exact match or Jaccard.
  • Tier 2 — Reasoning (8 q): Multi-step calculation. Laxity severity, SpeculumFreshness states, sorry-depth SLO. Scored semantically.
  • Tier 3 — Legal (6 q): Compliance reasoning. IRAP ISM-0839, EU AI Act Art.13, SRA Principle 6, GDPR Art.44. Legal concept coverage.
  • Tier 4 — Code (6 q): Code generation and review. Elixir KL-divergence, Lean 4 stubs, UCB1, Wave 4 bug fix. Rubric-scored.
  • Tier 5 — Metacog (5 q): Self-referential stack questions — sorry depth SLO, drift detection, CoverageOracle. Semantic scoring.

Scoring methods

  • exact_match: Normalise, compare strings — 0.0 or 1.0.
  • semantic (Jaccard): Word-set intersection / union. No embedding calls required.
  • rubric: Criteria list (substring/regex checks). Score = fraction met.

Running live benchmarks

  • Set env vars (see .env.example in repo)
  • mix bench_arena.run --adapter all
  • mix bench_arena.report --format html
  • Stack services: ports 4001–4004 (Elan/TokenGov/CSC/Recursa)
π = acc_δ − 0.001 × lat_δ − 0.0001 × tok_δ
acc_δ = adapter accuracy − baseline accuracy lat_δ = adapter mean latency − baseline latency (ms) tok_δ = adapter mean tokens − baseline tokens

What is Baseline?

Baseline is currently a stub that echoes the reference answer with slight perturbation (~0ms latency, ~112 tokens). This means AIME scores 100% (the answer is already known) while MMLU scores 0% (full text returned instead of MCQ letter). Next step: wire baseline to a real single-shot Perplexity sonar API call for honest single-turn scores.

No-fabrication contract. BenchArena never synthesizes performance data. Adapters without API credentials return N/A for live scores. Where public benchmark scores are shown, they are sourced from published evaluations — not BenchArena runs.
