Stack

4-step RAG-grounded pipeline

Phase 1–3 upgraded. 4-step protocol: decompose the question into sub-questions → retrieve (Perplexity sonar per sub-question, citation-grounded, up to 5) → verify (augmented with retrieved passages; prefers sources over decomposition on conflict) → synthesise (CompetenceSignal-gated output vocabulary). ConfabulumGate halts pipeline if confabulum score > 0.65 on any of 9 types. ConfidenceScore propagates through DAG — mapped to CertaintyVocabulary: Verified (≥0.95) / HighConfidence (0.80–0.95) / Moderate (0.60–0.80) / Uncertain (0.40–0.60) / Halted (<0.40). EscalationGate (I11): material decisions require human auth token (FINRA 3110/3120). TruthfulQA regression target: ≥95%.

KEY FINDINGS — Complete 25q run, 2026-04-07

  • Phase 1 (Epistemic Integrity): Stack adapter upgraded to RAG-grounded 4-step protocol. TruthfulQA regression target: ≥95% (was 53.3%). ConfabulumRate promoted from classifier to pipeline gate — halts synthesis at score > 0.65 across 9 confabulum types. ConfidenceScore propagated through DAG, mapped to CertaintyVocabulary.
  • Phase 2 (Audit Trail): GroundtraceRecord: per-SubTask signed hash-chain audit trail. Every execution step produces a tamper-evident record — SHA-256 chained, reconstructable by auditors. Maps to FINRA Rule 17a-4 / SEC books-and-records. Tamper-evidence proved in Lean 4.
  • Phase 3 (Agentic Risk Controls): EscalationGate (I11): material decisions require human auth token (FINRA 3110/3120). CompetenceSignal: synthesis vocabulary gated by confidence level — no confident-sounding output when confidence < 0.60. PathwayAudit: every DAG edge inspected against deontic obligation set (PII, solicitation, freshness, hedging). 8 theorems proved in Lean 4.
  • Stack ties perplexity_standard (58.7% each) but costs 4.3× more tokens (1,910 vs 448) and 2.9× more latency (11.8s vs 4.1s) — the 3-step decompose/verify/synthesise protocol adds structure but no accuracy gain on these 25 questions vs a single sonar call. The value of the stack shows up in other dimensions (compliance, auditability, metacognition) not captured by MCQ accuracy.
  • Agent loop underperforms standard on MMLU (40% vs 60%) — 3-turn chat with plan/execute/reflect can over-elaborate and drift from the correct MCQ answer.
  • GPQA Diamond is flat across all live adapters at 40% — this is a genuine capability ceiling for sonar. Claude Opus 4.6 (91.3%) and Gemini 3.1 Pro (94.3%) from public leaderboards show what's possible with stronger models.
  • IFEval is a stack/standard bright spot: both hit 100% — instruction following under verifiable constraints is where structured prompting pays off.
  • AIME = 0% for all non-stub adapters — sonar is not a reasoning model. The baseline's 100% is a stub artefact (echoes reference answer).
  • Token efficiency: standard uses 448 tokens avg vs stack's 1,910 for identical accuracy — the stack costs 4.3× per query. Worth it for compliance/auditability; not for raw MCQ throughput.
Baseline caveat ⚠️ The baseline adapter echoes the reference answer directly (stub). This inflates AIME to 100% (it knows the answer) and deflates MMLU to 0% (returns full text, not MCQ letter). Baseline overall of 54.3% is an artefact — not a real single-turn capability measurement.

How it works

Methodology

Question tiers

  • Tier 1 — Factual (10 q): Short lookups. Shannon entropy, IRAP, UCB1, Schnorr. Scored by exact match or Jaccard.
  • Tier 2 — Reasoning (8 q): Multi-step calculation. Laxity severity, SpeculumFreshness states, sorry-depth SLO. Scored semantically.
  • Tier 3 — Legal (6 q): Compliance reasoning. IRAP ISM-0839, EU AI Act Art.13, SRA Principle 6, GDPR Art.44. Legal concept coverage.
  • Tier 4 — Code (6 q): Code generation and review. Elixir KL-divergence, Lean 4 stubs, UCB1, Wave 4 bug fix. Rubric-scored.
  • Tier 5 — Metacog (5 q): Self-referential stack questions — sorry depth SLO, drift detection, CoverageOracle. Semantic scoring.
  • Tier 7 — Hallucination (45 q): TruthfulQA (15 MCQ), SimpleQA (15 factual recall), BBH (15 reasoning). Exact match + semantic.
  • Tier 8 — LegalLean (25 q): DDL formal reasoning: deontic conflict (5), defeat acyclicity (5), temporal scope (5), modality (5), IRAP compliance (5). Rubric + exact match.

Scoring methods

  • exact_match: Normalise, compare strings — 0.0 or 1.0.
  • semantic (containment-first): For short references (≤5 words), checks verbatim containment in the answer — correct for SimpleQA-style short-fact questions where models answer in prose. Falls back to Jaccard word-overlap for longer references.
  • rubric: Criteria list (substring/regex checks). Score = fraction met.
  • confabulum_gate: Pipeline halts if confabulum score > 0.65 on any of 9 confabulum types (factual_error, temporal_confusion, entity_substitution, causal_inversion, scope_collapse, authority_fabrication, numeric_drift, modal_confusion, negation_flip). A halted pipeline scores 0.0.

  • Set env vars (see .env.example in repo)
  • mix bench_arena.run --adapter all
  • mix bench_arena.report --format html

What is Baseline? ⚠️

Baseline is a stub that echoes the reference answer with slight perturbation (~0ms latency, ~112 tokens). AIME scores 100% (answer already known) while MMLU scores 0% (full text returned instead of MCQ letter). The 54.3% overall is an artefact. HumanEval 82% and IFEval 90% are partially valid since rubric scoring picks up structure from the echoed reference.

No-fabrication contract. BenchArena never synthesizes performance data. Adapters without API credentials return N/A for live scores. Where public benchmark scores are shown, they are sourced from published evaluations — not BenchArena runs.
